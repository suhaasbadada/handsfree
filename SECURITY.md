# Security

HandsFree is pre-release software. Only the current Mac beta is maintained; there is no formal support window or response-time guarantee. Updates are manual. A local self-signed build is not notarized or Apple-approved.

Please do not post sensitive vulnerabilities, recordings, transcripts, credentials, or personal diagnostics in public issues. On GitHub, use **Security → Report a vulnerability** if private vulnerability reporting is enabled. If it is unavailable, open a minimal issue asking the maintainer to establish a private reporting channel, **without exploit details or private data**. No dedicated security email is advertised.

For ordinary bugs, use the bug template with invented sample text and redacted logs. See [privacy and diagnostics](docs/DEVELOPMENT.md) for what is stored locally. Do not disable macOS security controls to work around an issue.
