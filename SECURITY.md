# Security

HandsFree is pre-release software. The Mac beta and experimental Windows implementation have no formal support window or response-time guarantee. Updates are manual. Mac builds are locally self-signed and not Apple-notarized; Windows builds are unsigned. Automated build checks do not establish hardware compatibility or security certification.

Please do not post sensitive vulnerabilities, recordings, transcripts, credentials, or personal diagnostics in public issues. On GitHub, use **Security → Report a vulnerability** if private vulnerability reporting is enabled. If it is unavailable, open a minimal issue asking the maintainer to establish a private reporting channel, **without exploit details or private data**. No dedicated security email is advertised.

For ordinary bugs, use the bug template with invented sample text and redacted logs. See [privacy and diagnostics](docs/DEVELOPMENT.md) and the [Windows testing guide](docs/WINDOWS.md) for platform details. Do not disable Gatekeeper, Windows Defender, or organization security policies to work around an issue.
