# HandsFree v0.1.1-beta.7

Prerelease preparation · **Candidate only, not a publication record**

Internal app version: **0.1.1**. Distribution label: **0.1.1-beta.7**.
The active public website and install guidance remain on verified beta 6 until
beta 7's publication and anonymous byte-verification gates pass.

## Signed in-app updates

Adds explicit **Updates → Check for updates**, then a confirmed **Download &
restart…** flow using a version-bound signed Apple Silicon updater archive.
No startup checks, automatic downloads, silent installations or downgrades.
See [update safety, privacy and limitations](../UPDATES.md). Beta 6 does not
contain this functionality: it needs an initial DMG/Homebrew bootstrap upgrade.

The DMG, updater archive and authorized bootstrap installation must reuse the
same final signed `release/updater/HandsFree.app`, including dependency notices
and corresponding sources inside its sealed resources. The raw build cache is
not that final bundle. The existing macOS signing identity is unchanged.

## Pending release evidence

No artifact source SHA, checksum, CI result, publication, installation or OTA
acceptance result is recorded yet. Packaging/audit must establish the exact clean
source, seven immutable public assets and anonymous byte equality before feed,
website and Homebrew activation. Do not infer live dictation or an actual updater
replacement/restart from unit tests or signature verification. Record actual
authorized installation/readiness and model/settings/usage preservation evidence
separately. A future updater-enabled release is needed for normal forward OTA
acceptance; beta 6 cannot exercise that path.

Apple Silicon, macOS 14+ only. Experimental, self-signed, not Developer ID signed
or notarized. No Apple approval, legal certification or separate-Mac QA claimed.
Historical beta 6 and older notes/assets remain unchanged. Windows work is paused;
Linux is unsupported.
