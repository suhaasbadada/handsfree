## Signed in-app updates

Adds footer **Updates → Check for updates**, then a confirmed **Download &
restart…** flow using a version-bound signed Apple Silicon updater archive.
Opening Updates reads the installed distribution locally; only Check contacts
GitHub. No startup checks, automatic downloads, silent installations or downgrades.
See [update safety, privacy and limitations](../UPDATES.md). Beta 6 and earlier
need an initial manual DMG/Homebrew bootstrap upgrade.

## Limitations

**Actual forward OTA replacement/restart was not performed:** no beta 8 exists.
Manual bootstrap, artifact equality and signature tests are not OTA acceptance.
Live audio/dictation acceptance and separate-Mac QA were **not performed**.
Native UI automation was not Accessibility-trusted; no permissions were changed
to enable it. Runtime readiness does not prove recording or editor insertion.

Apple Silicon, macOS 14+ only. Experimental, self-signed, not Developer ID signed
or notarized. No Apple approval or legal certification. Historical beta 6 and
earlier notes/assets remain unchanged. Windows work is paused; Linux unsupported.
