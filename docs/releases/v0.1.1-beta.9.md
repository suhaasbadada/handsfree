# HandsFree v0.1.1-beta.9

Prerelease · **Published experimental Mac beta**

Internal app version: **0.1.1**. Distribution label: **0.1.1-beta.9**.

## Updater repair and dialog layout

- Fixes the download-time TLS panic behind “The update operation stopped
  unexpectedly.” Restored signed metadata now explicitly initializes the ring
  crypto provider, without replacing a provider already chosen by the process.
- Available updates show two actions, avoiding the awkward three-button wrap.
- Both dialogs initially focus their headings, without highlighting Close or
  Not now. Keyboard navigation retains visible focus; Enter on the confirmation
  heading does not authorize installation.

## Bootstrap and acceptance boundaries

The actual beta 7 → beta 8 attempt failed before installation. Both immutable
published binaries contain the old downloader defect, so they cannot repair
themselves through the feed. The owner authorized one manual beta 9 bootstrap,
preserving the app's signing identity, model, preferences and usage totals.
This is a repair installation, **not a successful in-app update/restart test**.

A fresh-process regression reproduced the original TLS panic and passes with the
fix. An explicit real-plugin test downloaded the public signed beta 8 archive,
verified it, installed into an isolated temporary bundle, checked its signature
and executable, and verified cleanup. It did not touch the installed app.
The authorized manual bootstrap completed: the installed executable matches the
final release bundle, the designated signing requirement is unchanged, and model
and usage/settings file hashes match after restart. Fresh diagnostics confirmed
idle, model ready, Microphone, Accessibility, Input Monitoring and hook connected.
Forward OTA restart, live audio/dictation and separate-Mac QA are not claimed.

Apple Silicon, macOS 14+. Experimental, self-signed, not notarized. Packaging uses
`npm run build:local` and the existing signing identity and updater key. No keys
are replaced; published historical assets and release notes remain unchanged.
Publication requires clean exact-source CI and seven-asset checksum, signature,
provenance, bundle-equality and anonymous public-download audits.
