# HandsFree v0.1.1-beta.11

Prerelease · **Unpublished experimental Mac candidate — group 1**

Internal app version: **0.1.1**. Distribution label: **0.1.1-beta.11**.
Current verified public downloads and signed feed remain on **beta 10** until
beta 11 passes its exact-source public artifact audit and activation gates.

## Guided setup and private microphone check

- A revisitable **Get started** checklist in Overview observes microphone,
  Accessibility and Input Monitoring permissions, the live shortcut hook, and
  the verified English model. Unknown readiness is not success. It is available
  from the HandsFree menu, Settings and practice setup help; ready returning users
  are not automatically shown the guide.
- Permission requests and the model download remain explicit user actions using
  the existing controls. Opening the guide or polling readiness does not prompt
  for consent, download a model or start recording. Granted permissions with a
  disconnected shortcut hook lead to quit-and-reopen guidance, not false readiness.
- The microphone input meter is bound to the existing, explicitly started private
  practice recorder. It creates no second recorder and saves no audio file.
  Missing readings mean waiting, not silence or success; finishing, cancellation
  and lost eligibility clear the meter. Input level is not a recognition-quality
  score, and practice still requires permissions and the model.
- Instructions reflect the configured shortcut and toggle/push-to-talk mode.
  **Start test** is a button-only check, not shortcut evidence. **Shortcut received**
  requires a real current-context native shortcut event; it proves receipt only,
  not successful recording, transcription or insertion. Navigation, focus loss,
  menus, clearing and binding/mode changes retire that evidence.

Private practice stays local to its editable field: no external paste, clipboard
fallback or usage increments. This group adds no new AI processing or model;
existing local recognition and external-delivery safeguards remain unchanged.
Existing totals, settings, model, installed app and signing/updater keys must be
preserved. Preparation does not install, launch or replace the existing app.

## Release and acceptance boundaries

This is preparation metadata, not publication evidence. Exact clean source SHA,
CI run, signed artifact hashes and local/draft/anonymous-public seven-asset audit
results must be recorded by the release owner after those gates actually run.
Do not activate website, static downloads or the updater feed before public audit.
For this release, the app repository and `suhaasbadada/homebrew-handsfree` cask must
agree on the distribution version, exact public DMG URL and verified SHA-256;
tap publication and remote readback are separate gates before claiming parity.

Live microphone/shortcut hardware acceptance, separate-Mac QA and real OTA
replacement/restart acceptance are **unverified**. Automated fixtures do not
establish any of these. Leave the installed app in place for the owner's
authorized in-app update; do not substitute a manual replacement or reset totals.

Apple Silicon, macOS 14+. Experimental, self-signed and not notarized. Reuse the
existing signing identity and updater keys; never replace them. Historical
release artifacts and evidence stay immutable. See [practice](../practice.md)
for privacy and evidence boundaries and [releasing](../RELEASING.md) for gates.
