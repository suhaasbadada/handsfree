# HandsFree v0.1.1-beta.15

Matching Homebrew cask published and remotely read back at tap commit
`00c39bcdfe6beb22cf44cc553df7542666e0171a`. Tap CI, website/feed deployment
and live byte checks are independent distribution gates, not installed-app acceptance.

Published experimental Mac beta · Apple Silicon · macOS 14+
Internal app version: **0.1.1**

## Scope

- **Settings → Appearance:** Light, Dark and System, defaulting to System.
  The choice persists in an isolated Store field without resetting other settings
  or usage statistics. Explicit choices match the native WKWebView and capsule;
  System truly removes the native override and follows macOS appearance.
- **Existing landing palette, not a brand repaint:** Light uses the exact paper,
  ink and muted-red landing palette with cream primary-button text. Dark is a warm
  adaptation; the website remains light-only. Existing app layout is preserved.
- **Persistent, prominent update footer:** a verified available version stays
  visible outside the update dialog. Not checked, up to date **at last check** and
  failed checks remain distinct. The footer reads local cached status only: no
  unsolicited feed checks, automatic download or auto-install. Fixed footer
  geometry keeps the layout stable.
- Beta 14's stale-offer refresh **before confirmation**, exact-version/revision
  reconfirmation and once-only signed updater remain unchanged. Opening the
  dialog or reading status does not authorize a feed check or installation.

This is a follow-up to the four completed beta 11–14 release groups, not a new
numbered release group. No new AI features, models or transcript history.

## Honest limitations

Experimental, self-signed and not notarized. No Apple approval or clean-machine
Gatekeeper certification. Metadata and source tests do not establish native
hardware behavior, VoiceOver/AXPress acceptance, separate-Mac QA or real OTA
replacement/restart. Those acceptance gates remain **unverified**; no microphone,
dictation, installed-app replacement or successful real OTA claim is made here.
Windows remains paused and Linux unsupported; this release is Mac-only.
