# HandsFree v0.1.1-beta.3

**Prerelease · Beta testing.** Apple Silicon macOS beta. Internal app version: **0.1.1**.

This refresh packages the current approved Mac app. Beta 2's published DMG was built from older source: reinstalling it did not deliver the later dashboard and sound updates. Beta 3 uses a new immutable download, with clean source provenance and checks that the current compiled frontend and cue bytes are inside the packaged app.

## Changes since the published Mac beta 2

- Stats-first **Your activity** overview: words, estimated time saved, and dictation totals. No transcript-history panel or disclosure/expander maze.
- **Clean** and **Warm** sound profiles: single start cue, matching double end cue; inline sound and volume controls. Mute, cancellation, and background processing retain their guarded behavior.
- Inline custom shortcut controls and recording time-limit settings; dictation continues processing in the background after recording ends.
- Current transcription cleanup filters and existing Whisper encoder/cancellation fixes.

Existing model files, settings, and usage totals stay in their existing local locations; normal updates do not reset or duplicate statistics. The bundle ID and existing signing identity are preserved. Reinstalling does not create a new onboarding state or revoke/regrant existing macOS permissions.

Once published, download `HandsFree-0.1.1-beta.3-macos-arm64.dmg`, quit HandsFree, replace the Applications copy, eject the image, and reopen Applications → HandsFree. There is no automatic updater. The distribution label changes to beta 3; the embedded app version remains 0.1.1. Windows beta 2 is independent and unchanged.

Requires **macOS 14+ and Apple Silicon**. The ~148 MB English model is downloaded once if not already present; dictation then runs on-device. Microphone, Accessibility, and Input Monitoring permissions require explicit approval. No paid account is needed.

**Experimental, self-signed, and not notarized.** Not Apple Developer ID signing or Apple approval. Follow [installation guidance](../INSTALL.md); do not bypass managed security policy. The [distribution decision and upstream SDK caveat](../RELEASING.md) still apply. Notices and dependency source copies accompany the DMG.

Review important transcripts: accuracy, editor insertion, hardware recording quality, and behavior on another Mac are not guaranteed. Secure Input, focus, permissions, and audio devices can affect operation. Clipboard fallback replaces clipboard contents. No clean-Mac Gatekeeper or separate-Mac interactive QA is claimed. Artifact checks and synthetic tests do not imply microphone or installation testing.

Verify the attached `SHA256SUMS`. Checksums detect corruption, not independent publisher identity. Keep the image's notices and source archive with redistributions.
