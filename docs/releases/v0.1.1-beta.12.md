## Recording controls

- Microphone selection saves the selected device UID, with an explicit **System
  default** option. A disconnected selected device never silently falls back to
  another microphone; select an available device or System default explicitly.
- The recording timer derives elapsed time from captured session samples. Its
  duration limit is frozen for that session, rather than changing mid-recording
  when settings change.
- Existing recording modes, duration limits and sound controls are retained and
  refined, not newly invented features. No new AI features are included.
- Practice controls use an actually stable layout across recording phases,
  errors and cancellation, rather than merely suppressing a status message.
  Focus transfer, including Clear, is handled without restoring the UI jump.
