**Unpublished experimental Mac beta candidate — group 3: Fit your workflow.**

notarized. Candidate preparation is not publication or installation evidence.
Current verified public downloads, website and signed feed remain **beta 12**.
The owner authorized four sequential feature releases, each with independent

## Candidate scope

- **Launch at login:** macOS ServiceManagement is OS-authoritative; no saved
  enabled boolean or automatic startup registration. Approval-required is not
  enabled. **Open Login Items** opens system settings without registering again;
  **Cancel pending registration** explicitly unregisters a pending request and
  refreshes actual status. Independent pending owners and stale-read protection
  preserve newer writes; operation errors are surfaced, not treated as success.
- **Temporary pause:** ephemeral, initially off each process; blocks new
  shortcut starts only, including shortcut-origin practice. Explicit **Start
  test** remains available. Pause does not cancel or retroactively reject an
  already accepted recording, physical hold or cue-waiting admission. Rejected
  held shortcuts require physical release before rearming.
- **App exclusions:** persisted bundle IDs apply to new external starts, not
  accepted sessions or explicit practice. The picker lists regular running-app
  metadata only, renders names as text and retains saved IDs for absent apps.
  It neither launches/activates apps nor requests Accessibility permission.
- **Quick controls:** dashboard brand menu and menu-bar Pause/Resume, plus
  existing Finish/Cancel. Menu Finish snapshots the displayed generation and
  uses generation-bound `Control::Finish(Some(generation))`; it cannot
  toggle into a new recording. Existing accepted hold release, cue completion,
  finish and cancel owners, FIFO, epoch and generation guards remain preserved.
- **Own-control clicks:** synthetic routing/hit-test coverage distinguishes the
  app's capsule/tray/menu controls from ordinary external clicks; it does not
  disable focus/security surveillance. Actual AppKit/window ordering and real
  status-item/menu event delivery remain **unverified**, not proven by fixtures.

No AI features, new models, per-app profiles, transcript history, snippets or
extra statistics. Existing recording modes, duration limits, sound controls,
microphone selection, session timer, practice and Compatibility paste remain.
See [workflow boundaries and synthetic tests](../WORKFLOW.md).
