# HandsFree v0.1.1 — stable candidate preparation

Prepared 2026-11-17. **Not published or available.** Active public downloads and
the signed feed remain **v0.1.1-beta.24** until the exact stable candidate passes
publication and anonymous-public audit. This is the first non-beta stable target,
not beta 25. Distribution version: **0.1.1**. Internal app version: **0.1.1**.

## Scope and implementation status

- Bug **#1**: Record again now sizes to its label instead of a fixed 104-pixel
  grid cell, including larger text. Tests check the rendered text/icon against
  actual button padding, not only its outer rectangle.
- Bug **#2**: the gear has no permanent selected fill; Back announces the Home
  heading instead of automatically focusing the editor. Explicit Private test
  actions still focus the editor, and keyboard focus remains visible. Native
  recording/privacy authorization is unchanged.
- Both bugs reproduced before the fixes in rendered regressions. Targeted and
  full Chromium checks now pass in light/dark and narrow layouts. The issues stay
  open until reviewed delivery and release acceptance; no native installed-app
  result is implied by these local checks.
- Candidate metadata, stable packaging names and stable/prerelease audit policy
  are being prepared independently of those fixes. Beta 24 → stable 0.1.1 is a
  semver upgrade; the bundle identifier remains `com.handsfree.local`.
- Existing signing identity and updater keys must be reused. Stable is a release
  channel label, **not Apple approval**: self-signed, not Developer ID signed and
  not notarized. No permission reset, new identity or model replacement is implied.

## Verification and pending release gates

Local verification passed **460 Node tests / 1 skipped**, **91 Rust tests / 3
ignored**, frontend build, formatting and strict Clippy. Full Chromium base/theme
and nine DOM suites passed. Actual offscreen macOS WebKit passed 48 Settings cases,
24 completed/empty action-label cases and a reversible overflow negative control.
No stable artifact hashes, source release SHA, remote CI, hardware or publication
receipt is asserted here; those gates below still require exact-candidate evidence.

Follow the authoritative [release process](../RELEASE-PROCESS.md) for branch
protection, exact-source review/CI, packaging, hardware/private acceptance,
publication, public audit, activation, separate Homebrew parity and installed
OTA/preservation gates. Stable metadata policy is recorded in the
[current release guide](../RELEASING.md#stable-v011-preparation--2026-11-17).
This candidate also requires audio calibration acceptance with the installed
dictation check.

All runtime, packaging, publication, activation, Homebrew and installed OTA gates
remain **pending** in this preparation record. Historical beta release notes are
