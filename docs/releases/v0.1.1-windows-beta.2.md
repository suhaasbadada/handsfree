# HandsFree for Windows — Experimental Beta 2

**Windows 10/11 x64 · CPU · English · unsigned · not yet live hardware-tested.**

[Download the installer](https://github.com/suhaasbadada/handsfree/releases/download/v0.1.1-windows-beta.2/HandsFree-0.1.1-windows-x64-setup.exe) · [Install and tester guide](https://github.com/suhaasbadada/handsfree/blob/main/docs/WINDOWS.md)

## Right Ctrl default and upgrades

New installations use a short **Right Ctrl** tap: release within **400 ms** to
start, speak, then tap again to finish. Escape cancels. Holds, repeats, keyboard
or mouse chords, AltGr, injected input and foreground-window changes cancel the
gesture. Normal Ctrl messages pass through; this is not a guarantee of universal
conflict-free behavior. Custom shortcuts remain available.

**Upgrading from beta 1? Existing saved shortcuts, including Ctrl+Shift+Space,
are preserved. Choose Settings → Use default to switch to Right Ctrl.** The
installer upgrade retains settings; the unchanged embedded app version is 0.1.1.
Quit HandsFree before running the new installer.

For a first installation, run the EXE, allow desktop microphone access in Windows
Settings, explicitly download the English model (~148 MB) in HandsFree Settings,
then test Right Ctrl in a disposable Notepad field. Setup requires internet and
WebView2; dictation runs locally after model download. Do not disable Windows
security protections to install this unsigned beta. Windows ARM and 32-bit
Windows are unsupported. Mac beta 2, Homebrew and Mac's Fn default are unchanged.
