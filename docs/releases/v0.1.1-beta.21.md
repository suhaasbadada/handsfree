# HandsFree v0.1.1-beta.21

Unpublished experimental Mac candidate · Apple Silicon · macOS 14+

Internal app version: **0.1.1**. `candidateRelease.publicAvailable` is false.
Public release/downloads, tracked signed feed, README and install guide remain
beta 20 until audited publication. No beta 21 signed artifacts, checksums,
exact-source CI or publication receipts exist in this preparation.

## Candidate scope and acceptance contract

- Native preaccept validation revision-checks the same device UID, formats and
  actual running state after output preparation and immediately before accept.
  A configuration notification after acceptance is fatal, not retry permission.
  The bounded two-attempt initial preparation contract is unchanged.
- Independent three-second hardware preparation and three-second cue/handoff
  budgets replace the false whole-session startup timeout. A prior diagnostic
  reached hardware at 2.633s and start cue at 2.857s, then the old combined
  watchdog incorrectly rejected the 180ms tail; that failed attempt is not a pass.
- Cancellation tombstones, FIFO ownership, generation/epoch boundaries, EOS
  retirement/drain and owner cleanup remain unchanged. No idle open microphone
  is introduced; cue-period PCM is discarded, not used as dictation input.
- UI corrections center labels, restore picker divider spacing, and guard preview
  work by quiescent phase. Compact Practice uses native waveform levels only,
  with a privacy-preserving fallback. Overview uses unboxed metrics and lightweight
  Practice/recovery rows. Light/Dark/System behavior remains unchanged.
- Product status moves to the top right and opens a direct recovery panel, not a
  Settings hunt. It separates runtime failure from granted permissions and model/
  shortcut readiness, with device selection and explicit recovery actions. Opening
  the panel performs no recording or permission request; private testing still
  requires an explicit Start.
- A subsequent owner-requested visual simplification removes enclosing rectangles
  from Overview, metrics, Practice and Settings. Typography, spacing and light
  dividers replace stacked cards; secondary actions lose filled backgrounds and
  primary controls use compact capsules. The status dialog's ready checks use
  compact rows. Direct recovery, readable fields and keyboard focus remain.
- Updates use the footer directly: click to check with a spinning refresh icon,
  then click Download & update for the displayed exact version. No update or
  confirmation modals remain. The feed is rechecked; a different version requires
  another click. Progress/errors stay inline and the existing signed native updater
  installs and reopens HandsFree. Ready Setup and duplicate Settings failure text
  are removed; missing requirements remain actionable. No installed OTA test is
  implied by UI/controller tests.

Acceptance requires the existing native/state contract regressions and browser
interaction checks to remain green, not frozen screenshot text. UI eligibility
does not authorize native capture. Broader device, installed dictation and OTA
acceptance remain separate from source and focused diagnostic evidence.
