# HandsFree v0.1.1-beta.2

**Prerelease · Beta testing.** Apple Silicon macOS beta. Internal app version: **0.1.1**.

**Upgrade recommended:** beta 1 could incorrectly cancel Whisper encoding, preventing transcription. This release fixes that false-abort callback; the fix was checked with the existing real model and synthetic audio, without recording microphone audio.

## Changes

- Correct Whisper's encoder callback so normal encoding continues and explicit cancellation still stops it.
- Make the first-run model download action visible in Settings, including clear download/progress and failure states.
- Preserve existing settings, model files, signing identity, and macOS permission identity when replacing the installed app.

Download `HandsFree-0.1.1-beta.2-macos-arm64.dmg`, quit HandsFree, replace the Applications copy, eject the image, and reopen Applications → HandsFree. There is no automatic updater. Beta 1 remains available only as release history; use beta 2 instead.

Requires **macOS 14+ and Apple Silicon**. The ~148 MB English model is downloaded once; dictation then runs on-device. Microphone, Accessibility, and Input Monitoring permissions require explicit approval. No paid account is needed.

**Experimental, self-signed, and not notarized.** This is not Apple Developer ID signing or Apple approval. Follow [installation guidance](../INSTALL.md); do not bypass managed security policy. The [distribution decision and upstream SDK caveat](../RELEASING.md) still apply. The DMG includes project/dependency notices and dependency source copies.

Review important transcripts: accuracy, editor insertion, hardware recording quality, and behavior on another Mac are not guaranteed. Secure Input, focus changes, permissions, and audio devices can affect operation. Clipboard fallback replaces clipboard contents. No clean-Mac Gatekeeper or separate-Mac interactive QA is claimed.

Verify the download against the attached `SHA256SUMS`. Checksums detect corruption, not independent publisher identity. Keep the image's notices and source archive with redistributions.
