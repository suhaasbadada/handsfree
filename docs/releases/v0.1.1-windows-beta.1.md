# HandsFree 0.1.1 — Windows Beta 1

**Experimental tester release · Windows 10/11 x64 · English**

This is the first Windows implementation. Automated Windows builds and tests
are not a substitute for testing microphones, editors, audio devices and
installation on a real PC. Please start with invented text in Notepad.

## Included

- Local English transcription with Whisper on the CPU; no account or paid API.
- Ctrl+Shift+Space by default, with an inline custom-shortcut recorder.
- A non-activating recording indicator with Finish and Cancel controls.
- Recording limits from two to five minutes and background processing during pauses.
- Clean/Warm cues, local usage totals and filtering of non-speech annotations.
- Conservative focused-field insertion and automatic clipboard fallback.
- A per-user EXE installer; WebView2 setup when the runtime is missing.

## First use

1. Download the Windows x64 setup EXE from this release and install as your normal
   user. This build is **unsigned**; Windows or your browser may warn or block it.
   Only proceed if you trust the official download. Respect managed-device policy;
   do not disable Defender or other security controls.
2. Open HandsFree and explicitly download the **English model (~148 MB)** from
   Overview or Settings. Ordinary dictation works offline after setup.
3. Enable desktop microphone access in Windows Settings if required.
4. Focus a Notepad text field, press **Ctrl+Shift+Space**, speak, and press the
   shortcut again to finish. **Escape** cancels. Review the result before use.

## Known boundaries

- x64 only; Windows ARM and 32-bit systems are not supported by this build.
- Fn is not a Windows shortcut option. Choose another combination if the default
  is already registered by another app.
- CPU transcription can be slower than the Mac Metal backend. Continuous speech
  without pauses still needs processing after Finish.
- Password, elevated, read-only and unsupported editors are refused for automatic
  insertion. A successful transcript is copied for manual paste instead.
- Copy fallback replaces the clipboard. Clipboard history/sync can retain text.
  Synthetic paste submission is not confirmation that an editor accepted it.
- The recording HUD has keyboard shortcuts, but its custom buttons do not yet
  expose full native accessibility semantics.
- No automatic updater or startup registration. This is not an Authenticode-signed
  or Microsoft-certified release.

See the [Windows testing checklist](https://github.com/suhaasbadada/handsfree/blob/main/docs/WINDOWS.md)
and report problems with your OS version, release tag, affected editor and
invented reproduction text. Do not upload recordings, real dictation or secrets.

The existing Mac DMG and Homebrew release are unchanged.
