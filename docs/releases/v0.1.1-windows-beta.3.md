# HandsFree for Windows — Experimental Beta 3

**Planned candidate, not yet published. Windows 10/11 x64 · CPU · English · unsigned · not yet live hardware-tested.**

Choose Settings → **Recording mode → Push to talk** to hold physical Right Ctrl
(or an existing custom combination), speak, and release to finish. Long holds
are supported; custom combinations finish on the first required component's
release. **Toggle remains the unchanged default**, including upgrades.

Other keys, mouse actions during a hold, AltGr/injected input, and observed focus
changes cancel. Focus surveillance continues through processing and delivery;
cancellation invalidates the session generation and cannot paste stale output.
Repeats and still-held keys do not restart cancelled recording. Escape and native
HUD Finish/Cancel remain available. Normal Ctrl messages still pass through;
choose a conflict-free shortcut. See [behavior and safeguards](../PUSH-TO-TALK.md).

Saved shortcuts, including older Ctrl+Shift+Space bindings, remain unchanged.
Settings → Use default selects Right Ctrl; it does not opt into Push to talk.
Models, statistics, sounds, volume and other preferences stay in place without
resetting totals or downloading a new model. Embedded app/installer version stays
0.1.1. Quit HandsFree before upgrading; no automatic updater.

The planned versioned installer is `HandsFree-0.1.1-windows-x64-setup.exe` under
tag `v0.1.1-windows-beta.3`. Existing Windows beta 2 public downloads remain
unchanged until native MSVC CI, complete artifact hashes, extracted AMD64 app and
OS-only direct-import dependency gate, notices/source payload, and anonymous
public asset bytes are verified. No build result or public availability is
claimed here. Final publication must include exact source/run IDs and hashes.

Setup requires internet and WebView2; first-time model download is ~148 MB.
Dictation then runs locally. Windows ARM and 32-bit Windows are unsupported.
Do not disable security protections for this unsigned beta. [Tester guide](../WINDOWS.md).

Automated checks do not establish live microphone capture, real keyboard hooks,
editor/paste behavior, clean-PC installation, dynamic DLL loading or SmartScreen
acceptance. Manual hardware acceptance remains pending. Review important output;
clipboard fallback replaces clipboard contents. Permission and target-focus
requirements are unchanged. No private audio, models, settings or signing
material are distributed; retain bundled notices and corresponding source.
