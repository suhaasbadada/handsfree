## Scope and user-request checkpoints

This candidate simplifies the desktop interface, not native capture. The active
public release and signed feed remain **beta 23**; candidate coordinates are
disabled. Implementation is not final verification or release acceptance.

The Home context merge is intentional: private native shortcut receipts can be
eligible on Home, but eligibility is **not** native authorization. Settings,
product-status dialogs, focus loss and update installation revoke pending private
intent and clear text/meter; returning restores eligibility, never starts capture.
Owner/FIFO/epoch/generation boundaries and native privacy guards remain unchanged.
The pending-check revocation fix in `Updates.installing` is an intentional UI
safety change, not a change to updater signatures, installer policy or capture.
