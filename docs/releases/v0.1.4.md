# HandsFree v0.1.4 — stable Mac candidate

Internal app version: **0.1.4**.

Checking for updates no longer shifts the footer, privacy label, GitHub icon,
or installed version. The same footer control becomes a single-line **Download
& update** button when a new version is available. Click it to install and reopen;
there is no extra dialog. The divider remains aligned with the header.

Apple Silicon and macOS 14 or later. Existing self-signed identity; not notarized.
v0.1.3 remains active until signed acceptance, publication and public verification.
