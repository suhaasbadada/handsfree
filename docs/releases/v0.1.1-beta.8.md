# HandsFree v0.1.1-beta.8

Prerelease · **Published experimental Mac beta**

Internal app version: **0.1.1**. Distribution label: **0.1.1-beta.8**.

## Updates dialog focus

Opening App updates now focuses the heading instead of the Close button, avoiding
an unintended selected-looking red outline. Keyboard navigation still gives
buttons visible focus rings. Escape closes the dialog and restores focus to its
trigger. Installation confirmation still defaults to **Not now**.

Regression checks cover initial/reopened focus, Tab focus visibility, Escape and
focus restoration, alongside the existing updater confirmation and failure tests.

## Distribution and acceptance

Apple Silicon, macOS 14+. Experimental, self-signed, not notarized.
Packaged with the existing app identity and dedicated updater key; no keys are
replaced. Older release assets and notes remain unchanged. The exact audited
beta 8 feed is checked in for Pages deployment; live feed/website and Homebrew
verification remain separate rollout gates, not consequences of publication.

This release is intended to test a real beta 7 → beta 8 **Updates → Check for
updates → Download & restart** upgrade. Do not manually replace the installed beta
7 app to claim that test passed. Actual installation/restart, data preservation
and readiness are separate acceptance gates and are not yet verified. The
installed beta 7 executable, signing requirement, model and usage/settings file
hashes were unchanged after packaging. Diagnostics are a live, changing file,
not part of the preserved preferences/usage baseline. Native UI automation lacks
Accessibility trust, so the user's explicit in-app clicks are still required;
no permissions were changed to automate them.
No live audio/dictation or separate-Mac acceptance is claimed.
