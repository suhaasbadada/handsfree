# HandsFree v0.1.1-beta.10

Prerelease · **Experimental Mac beta candidate**

Internal app version: **0.1.1**. Distribution label: **0.1.1-beta.10**.

## A quieter dashboard, working private practice

- Practice-first layout, accessible icon actions, compact activity cards, and a
  cleaner footer. Sample: “A little less typing. A little more thinking.”
- With Overview focused, your shortcut routes to isolated practice. Words appear
  directly in its editable text box without pasting, clipboard fallback or usage
  increments. Existing totals remain unchanged; historical tests are not deducted.
- Toggle and push-to-talk retain separate physical-input, view-context and
  recording ownership. Early releases finish after start acknowledgement; stale
  focus/navigation events cannot revive a cancelled test.
- Click the menu-bar logo for Open HandsFree, Practice dictation, Settings,
  App updates, Cancel and Quit. The dashboard logo has a keyboard-accessible menu.
- Own-app delivery refusals no longer copy text or publish usage. External paste
  protections remain unchanged.
- Includes the typed state contracts and repaired signed updater from beta 9.

## Upgrade and verification boundaries

Leave the existing beta 9 installation in place. Choose **Updates → Check for
updates → Download & restart** after this release is published and the signed
feed is activated. No manual replacement of the installed app is part of this
release. Preserve signing identities, permissions, model, preferences and totals.

Automated Node and Rust tests, Clippy, frontend build, responsive browser smoke
and real frontend event-listener integration are local gates. Release publication
additionally requires exact-source CI and local/draft/public seven-asset signature,
checksum, provenance and complete signed-bundle equality audits. These are not a
claim that live microphone capture, real in-app replacement/restart or separate-Mac
acceptance has passed. Those remain unverified until actually exercised.

Apple Silicon, macOS 14+. Experimental, self-signed and not notarized. Existing
signing/updater keys are reused, never replaced. Historical releases stay immutable.
